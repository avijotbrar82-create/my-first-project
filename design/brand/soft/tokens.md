# Verta Relief — Soft design tokens

A warm, editorial, boutique-wellness alternative to the Kinetic theme.
Palette derived from the reference gift-box photo: cream/oat/greige neutrals + a single honey accent.

## Color
| Token | Hex | Use |
|-------|-----|-----|
| cream | #F4EFE6 | page background |
| oat | #EAE2D3 | alternating section bands |
| greige | #CFC6B6 | soft blocks, hero/CTA halos |
| panel | #FBF8F1 | cards |
| honey | #B0732E | primary accent / CTA (the one accent) |
| honey-lt | #C58A3D | accent hover / glow |
| clay | #9C6B4E | kraft / botanical line tone |
| espresso | #3B322A | headings / body text / footer bg |
| taupe | #7A6F62 | secondary text / labels |
| line | rgba(59,50,42,.13) | hairline borders |

## Type
- Display: **Fraunces** 500/600 + 500 italic (headlines, prices, review quotes; italic honey accent words)
- Body: **Nunito Sans** 400/600/700 (paragraphs, nav, labels)

## Signature
Softened recovery pulse — a gentle rounded heartbeat line in a warm circle (logo + section dividers).
Breathing warm halos behind hero/spotlight/CTA, botanical sprig line motif, faint paper grain,
generous whitespace and slow fades. Commits to a single warm light theme (no dark mode) by design.

## Notes
Product covers use soft placeholder line-art with "photo coming" slots, awaiting
light-background product photography that will drop into the same slots.
